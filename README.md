# ワリカン帳

飲食の品目ごとに立替額と負担する人を記録し、最後の精算額を計算する静的なWebアプリです。

## できること

- メンバーと品目を自由に追加・編集
- 品目ごとに、立て替えた人を複数指定して支払い割合を設定
- 品目の負担者を選択し、選んだ人の間で均等に分割
- メンバーごとの立替額・負担額・差額と、送金先の精算メモを表示
- 入力内容をブラウザ内に自動保存し、精算メモをコピー

## 使い方

1. メンバー名を入力します。
2. 「品目を追加」から料理や飲み物と金額を登録します。
3. 「だれが立て替えた？」で支払った人を追加し、必要なら割合を調整します。割合は合計100%になるよう、ほかの人に自動配分されます。
4. 「だれの分？」で負担する人を選びます。選んだ人の間で金額を均等に分けます。
5. 下部の精算結果に表示される送金メモを確認します。

円単位で割り切れない場合は、選択順に1円ずつ配分します。入力データは利用中のブラウザのローカルストレージに保存され、サーバーには送信されません。

## 起動

ビルドや依存パッケージは不要です。index.htmlをブラウザで開くと使えます。静的ホスティングに配置すれば、Web上でも利用できます。
